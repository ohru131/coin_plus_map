# 現在地優先表示と店舗追加情報 検証記録

## 2026-08-20

ブラウザが初回位置情報を拒否した場合、「現在地を取得しませんでした。エリアまたはキーワードから店舗を探せます。」と表示し、検索・地図・店舗一覧の通常利用を継続できることを確認した。

店舗一覧から選択すると、詳細シートに営業時間と公式サイトの欄が表示され、公開情報取得中は読み込み状態を示す。該当するOpenStreetMap公開情報がない店舗では、営業時間と公式サイトが未掲載であることを明示し、来店前に確認するよう案内する。店舗を中心に地図を移動した後も、地図範囲内の店舗一覧が連動することを確認した。

公式COIN+の店舗CSVは店舗名・都道府県・市区町村・住所・ジャンルの5列であり、営業時間と公式サイトは含まれていない。そのため、追加情報は選択した店舗についてのみOpenStreetMapの公開情報から取得し、掲載がある場合だけ表示する。

京都市中京区のテスト位置情報を許可した状態で確認した。対象エリアは京都市へ自動選択され、地図は現在地へ移動し、現在地と同じ町名の店舗を先頭に、70m・110m・790mのような距離順で一覧へ表示した。距離は座標を取得できた店舗にのみ表示する。位置情報は店舗データとともに外部送信・保存せず、ブラウザ上の現在地取得と地図・距離計算にだけ利用する。
