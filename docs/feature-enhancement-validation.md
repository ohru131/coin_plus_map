# 集約マーカー・店舗名候補・PWA案内 検証記録

## 2026-08-21 ローカル検証

更新済みの検証タイル（11,061件の座標付き店舗）を使い、アプリの初期表示で低ズーム集約マーカーとPWA利用案内が表示されることを確認した。検索欄へ「ローソン高」と入力すると、検索索引を遅延読込して店舗名候補を最大8件表示し、京都市・大阪市・高槻市の該当候補と住所・ジャンルを確認できた。検索結果は22件となり、コンビニ・スーパーのジャンル件数も22件へ連動した。

候補「ローソン高槻京口町」を選択すると、候補一覧を閉じたうえで検索欄へ正式名称を設定し、一覧・ジャンル件数ともに1件へ絞り込めた。

店舗名の絞り込みを解除して高槻市を選択すると、低ズームの集約表示は2地域・348件となり、ジャンル別件数も飲食112件、コンビニ・スーパー30件など高槻市の条件へ切り替わった。

高槻市の地図をズーム11まで戻した状態でも、個別ピンではなく2つの集約マーカーと「2地域・348件を集約表示」が描画された。

同じ低ズーム状態で飲食フィルターを選択すると、集約表示・一覧ともに112件へ絞り込まれた。ブラウザの`offline`イベントを発火し、通信断時案内の表示を続けて確認する。

`offline`イベント後、画面上部に「以前に読み込んだアプリ画面と店舗データは表示できるが、新規取得には通信が必要」と明記したバナーが表示された。高槻市・飲食の低ズーム集約表示（2地域・112件）と既読の一覧は維持された。

本番ビルドには`manifest.webmanifest`、`sw.js`、アプリアイコンが出力された。ローカルの本番プレビューでは外部ストレージ上の旧形式店舗JSONを取得できず店舗データの表示はできないが、これはGitHub Pagesワークフローが公開時にマニフェストをバージョン付きタイル形式へ置き換える運用によるものである。

GitHub Pages公開版では、更新済みのマニフェストから7地域・11,061件の低ズーム集約を読み込み、検索語「ローソン高」に対して店舗名候補を8件表示できた。候補表示と同時に該当22件の店舗一覧・ジャンル件数も更新された。デプロイワークフロー`32431950551`は成功し、タイル生成、静的ビルド、GitHub Pages公開が完了している。
