# スマホ向け地図UI 検証記録

## 2026-08-20

381×679pxのスマホ幅で確認した。ヘッダーは2行の短い説明に収まり、検索・対象エリア・ジャンル・現在地ボタンは1画面幅で操作できる。地図は検索条件の直後に配置されるため、従来のように長い店舗一覧の後ろへ隠れない。

スマホ幅ではLeafletの標準ポップアップを表示せず、ピンまたは一覧で選択した店舗をアプリ全体の下部詳細シートで表示する。これにより、店舗情報、地図上の件数、凡例、Leaflet操作ボタンが同じ地図領域で重なる問題を回避する。凡例は「ピンの色」ボタンから必要な場合のみ展開する。

GitHub Pages公開版でも、検索条件、地図、店舗一覧の順で要素が配置され、Leaflet地図とジャンル別クラスタが読み込まれることを確認した。公開URLは`https://ohru131.github.io/coin_plus_map/`である。
