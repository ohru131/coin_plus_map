# Leaflet移行・検証記録

## 2026-08-20

開発プレビューで、Leaflet上にOpenStreetMap標準タイルが表示されることを確認した。地図にはLeafletおよびOpenStreetMap contributorsの帰属表示があり、初期表示では検索結果先頭100件を対象に住所座標の取得が開始され、クラスタ数値の表示も確認した。

同時に、京都市・大阪市・茨木市・高槻市を対象とする店舗件数、ジャンル別複数選択フィルター、地図範囲内店舗一覧の各UIが描画されることを確認した。

飲食フィルターを選択すると、一覧が飲食店のみに更新され、選択解除の導線が表示されることを確認した。さらに、一覧の「【ＡｉｒＰＡＹ】出町座のソコ」を選択すると、Leaflet地図が該当住所へ移動し、店舗詳細モーダル、Google Maps検索リンク、現在地からの徒歩経路リンクが表示された。
