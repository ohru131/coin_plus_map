# 段階的ピン描画 検証記録

## 2026-08-20

公開版 [`COIN+ ストアマップ`](https://ohru131.github.io/coin_plus_map/?v=0838b0b) で、初期表示では地図のピン描画を **3,600件 / 11,062件** に抑え、`表示範囲に応じて段階描画`および`拡大すると追加表示`の案内を表示することを確認した。

ズーム操作後には地図の表示範囲を再評価し、候補ピン数が11,017件へ更新されることを確認した。地図移動・ズーム完了後に候補を再計算し、初期300件から450件ずつ45ミリ秒間隔で描画上限まで追加する。範囲内店舗の一覧はピンの描画上限とは独立して全該当店舗を対象にし、100件単位で段階的に表示する。

さらに拡大したズーム倍率12では、候補が2,133件まで減少し、**2,133件 / 2,133件**の全候補ピンを描画できることを確認した。座標未取得の表示は、描画上限ではなく座標なし店舗数を基準にして表示する。
