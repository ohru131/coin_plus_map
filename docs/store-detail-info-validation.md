# 店舗詳細情報の調査記録

## 初期確認

公開版で店舗一覧を読み込み、代表例として「ローソンＯＳＬ夢洲駅」を選択して詳細情報の取得を開始した。現行実装は、店舗座標から80m以内のOpenStreetMap要素を検索し、`name`または`name:ja`がCOIN+側の店舗名と完全一致する場合だけ、`opening_hours`と`website`を利用する。

したがって、COIN+データに営業時間・公式サイトは含まれず、OpenStreetMap側で名称、営業時間、公式サイトのすべてが登録・一致していない店舗は未取得となる。次に、照合失敗と情報未掲載を区別し、公式の確認先へ移動できる画面へ改善する。
