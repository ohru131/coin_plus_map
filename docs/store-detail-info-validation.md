# 店舗詳細情報の調査記録

## 初期確認

公開版で店舗一覧を読み込み、代表例として「ローソンＯＳＬ夢洲駅」を選択して詳細情報の取得を開始した。現行実装は、店舗座標から80m以内のOpenStreetMap要素を検索し、`name`または`name:ja`がCOIN+側の店舗名と完全一致する場合だけ、`opening_hours`と`website`を利用する。

したがって、COIN+データに営業時間・公式サイトは含まれず、OpenStreetMap側で名称、営業時間、公式サイトのすべてが登録・一致していない店舗は未取得となる。次に、照合失敗と情報未掲載を区別し、公式の確認先へ移動できる画面へ改善する。

## 公開版の確認

GitHub Pagesデプロイワークフロー`32434148812`の成功後、公開版で店舗一覧を再取得し、代表店舗「ローソンＯＳＬ夢洲駅」の詳細表示を起動した。更新後は、近接する公開地図情報に該当店舗がない場合、公開情報を取得できない場合、項目が未登録の場合を区別して表示する実装となっている。営業時間・公式サイトをCOIN+の公式データとして誤認させず、Google Mapsおよび公式COIN+店舗検索へ移動できるようにした。

代表店舗では「近くの公開地図情報に、店舗名が一致する地点を確認できませんでした」と営業時間・公式サイトの両方に表示され、原因を具体的に確認できた。詳細モーダルには「Google Mapsで確認」「公式COIN+検索」と、店舗名・住所を引き継ぐ「Google Mapsで店舗情報を確認」の導線が表示されることを確認した。
